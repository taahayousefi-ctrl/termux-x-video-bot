# ربات تلگرامی دانلود ویدیوی X/Twitter برای Termux

این پروژه یک ربات **سبک و شخصی** است که روی گوشی اندرویدی و داخل Termux اجرا می‌شود. لینک یک پست عمومی `x.com` یا `twitter.com` را برای ربات می‌فرستید؛ ربات ویدیوی بومیِ آن پست را به‌صورت MP4 دریافت و در همان گفت‌وگوی تلگرام ارسال می‌کند.

> این ربات فقط باید برای محتوایی استفاده شود که حق دانلود و اشتراک‌گذاری آن را دارید. پست‌های خصوصی، محتوای محدودشده و پیوندهای سرویس‌های دیگر مانند YouTube پشتیبانی نمی‌شوند.

| ویژگی | پیاده‌سازی |
|---|---|
| زبان و وابستگی | Python 3 و **فقط کتابخانهٔ استاندارد**؛ هیچ `pip install` لازم نیست. |
| دریافت پیام | Long Polling با `getUpdates`؛ سرور عمومی، دامنه و webhook لازم نیست. |
| استخراج ویدیو | API عمومی FxEmbed برای پست‌های عمومی X/Twitter. |
| فایل ویدیویی | فقط نسخه‌های MP4 مستقیم؛ **بدون FFmpeg**، تبدیل، ادغام صوت/ویدیو یا تغییر کیفیت. |
| ارسال به تلگرام | بارگذاری `multipart/form-data` با کتابخانهٔ استاندارد Python. |
| سقف پیش‌فرض | 49 MiB برای حاشیهٔ امن زیر حد آپلود 50 MB تلگرام. |

## محدودیت‌های آگاهانه

این پروژه برای سبک بودن عمداً از FFmpeg استفاده نمی‌کند. بنابراین اگر پست فقط جریان `m3u8` داشته باشد، یا کوچک‌ترین نسخهٔ MP4 آن از سقف حجم عبور کند، ربات آن را ارسال نمی‌کند. برای ویدیوهایی که چند کیفیت MP4 دارند، ابتدا بهترین کیفیت را امتحان می‌کند و در صورت بزرگ بودن، خودکار به کیفیت پایین‌تر می‌رود. سرویس‌های عمومی X/Twitter ممکن است ساختار یا دسترسی خود را تغییر دهند؛ در آن حالت API واسط هم ممکن است موقتاً پاسخ ندهد.

تلگرام برای `sendVideo` فایل MPEG-4 را پشتیبانی می‌کند و سقف فعلی آن 50 MB است؛ ربات با سقف 49 MiB کار می‌کند تا خطای مرزی نداشته باشد. دریافت به‌صورت Long Polling با `getUpdates` نیز به یک دستگاهِ در حال اجرا نیاز دارد و webhook فعال نباید برای آن ربات تنظیم شده باشد. [1] [2]

## آماده‌سازی در Telegram

ابتدا در تلگرام به [@BotFather](https://t.me/BotFather) بروید، دستور `/newbot` را ارسال کنید، نام و username ربات را تعیین کنید و **توکن** تولیدشده را کپی کنید. توکن مانند گذرواژه است؛ آن را در پیام، تصویر، کد، Issue یا مخزن GitHub منتشر نکنید. اگر افشا شد، از BotFather آن را revoke کرده و توکن جدید بگیرید.

## نصب در Termux

در Termux فقط Python و Git لازم است. دستورهای زیر را به‌ترتیب اجرا کنید؛ `YOUR_GITHUB_USERNAME` را با نام کاربری GitHub خودتان جایگزین کنید.

```bash
pkg update
pkg install python git

git clone https://github.com/YOUR_GITHUB_USERNAME/termux-x-video-bot.git
cd termux-x-video-bot
```

سپس توکن را تنها در نشست فعلیِ Termux قرار دهید و ربات را اجرا کنید:

```bash
export BOT_TOKEN='توکن_دریافتی_از_BotFather'
python bot.py
```

پس از دیدن پیام «ربات فعال است»، در گفت‌وگوی خصوصی با ربات، `/start` را بفرستید و سپس یک لینک پست عمومیِ دارای ویدیوی بومی X/Twitter ارسال کنید. برای توقف امن، در Termux کلیدهای `Ctrl+C` را بزنید.

## محدود کردن ربات به حساب خودتان

در حالت پیش‌فرض، ربات برای هر کاربری که آن را پیدا کند پاسخ می‌دهد. این حالت فقط برای گرفتن شناسهٔ عددی خودتان در راه‌اندازی اولیه است. در گفت‌وگوی خصوصی با ربات دستور زیر را ارسال کنید:

```text
/id
```

ربات شناسهٔ عددی شما را نشان می‌دهد. برنامه را با `Ctrl+C` متوقف کنید، سپس با قراردادن آن شناسه در `ALLOWED_USER_IDS` دوباره اجرا کنید:

```bash
export BOT_TOKEN='توکن_دریافتی_از_BotFather'
export ALLOWED_USER_IDS='123456789'
python bot.py
```

برای چند کاربر مجاز، شناسه‌ها را با کاما جدا کنید؛ مثلاً `123456789,987654321`. پس از فعال‌کردن این محدودیت، ربات فقط به همین حساب‌ها پاسخ می‌دهد.

## نگهداری امن تنظیمات روی گوشی

برای اینکه لازم نباشد توکن را هر بار تایپ کنید، یک فایل خصوصی در پوشهٔ خانگی Termux بسازید. این فایل **خارج از مخزن Git** است و با سطح دسترسی محدود ذخیره می‌شود.

```bash
mkdir -p ~/.config
cat > ~/.config/x-video-bot.env <<'EOF'
export BOT_TOKEN='توکن_دریافتی_از_BotFather'
export ALLOWED_USER_IDS='123456789'
EOF
chmod 600 ~/.config/x-video-bot.env
```

در هر اجرا ابتدا تنظیمات را بارگذاری کنید و سپس ربات را آغاز کنید:

```bash
cd ~/termux-x-video-bot
source ~/.config/x-video-bot.env
python bot.py
```

## اجرای طولانی‌تر روی موبایل

برای اجرای پیوسته، گوشی باید روشن و متصل به اینترنت باشد. همچنین در تنظیمات Android، برای برنامهٔ Termux بخش Battery را روی **Unrestricted** یا معادل آن بگذارید. اگر دستور `termux-wake-lock` روی دستگاه شما موجود است، پیش از اجرا آن را فعال کنید تا گوشی به خواب عمیق نرود؛ برای آزادسازی بعدی از `termux-wake-unlock` استفاده کنید. [3]

```bash
cd ~/termux-x-video-bot
source ~/.config/x-video-bot.env
command -v termux-wake-lock >/dev/null && termux-wake-lock
nohup python bot.py > bot.log 2>&1 &
echo $! > bot.pid
```

برای دیدن لاگ و توقف ربات این دستورها را اجرا کنید:

```bash
cd ~/termux-x-video-bot
tail -f bot.log

# در یک نشست دیگر، برای توقف:
kill "$(cat bot.pid)"
command -v termux-wake-unlock >/dev/null && termux-wake-unlock
```

Android ممکن است فرایندهای پس‌زمینه را، به‌خصوص در حالت ذخیرهٔ باتری، متوقف کند. بنابراین این روش برای استفادهٔ شخصی مناسب است، اما تضمین سرویس 24 ساعته مانند سرور حرفه‌ای نیست.

## تنظیمات اختیاری

| متغیر محیطی | پیش‌فرض | کاربرد |
|---|---:|---|
| `BOT_TOKEN` | ندارد | الزامی؛ توکن ربات از BotFather. |
| `ALLOWED_USER_IDS` | خالی | شناسه‌های عددی مجاز، با کاما جدا شوند. |
| `MAX_UPLOAD_BYTES` | `51380224` | حداکثر حجم فایل قبل از ارسال. مقدار باید حداکثر `52428800` باشد. |
| `DOWNLOAD_DIR` | `downloads` | پوشهٔ موقت دانلود. فایل پس از ارسال یا خطا حذف می‌شود. |

## رفع خطاهای متداول

| پیام یا وضعیت | علت محتمل | اقدام |
|---|---|---|
| «در این پست ویدیوی بومی X پیدا نشد» | پست عکس، پیوند YouTube یا رسانهٔ غیر بومی دارد. | لینک پست دیگری با ویدیوی بارگذاری‌شده داخل X بفرستید. |
| «هیچ نسخهٔ MP4 … در سقف حجم … جا نشد» | فایل از حد قابل بارگذاری ربات بزرگ‌تر است. | بدون FFmpeg فشرده‌سازی ممکن نیست؛ پست کوتاه‌تر یا نسخهٔ کوچک‌تر لازم است. |
| «اطلاعات پست X قابل دریافت نیست» | اختلال اینترنت، خصوصی بودن پست یا اختلال موقت سرویس متادیتا. | اینترنت و عمومی‌بودن پست را بررسی کنید و کمی بعد دوباره امتحان کنید. |
| ربات پاسخ نمی‌دهد | برنامه متوقف شده، توکن اشتباه است یا webhook قدیمی فعال بوده است. | `python bot.py` را در Termux اجرا و `bot.log` را بررسی کنید. برنامه هنگام آغاز تلاش می‌کند webhook قبلی را حذف کند. |
| Termux ربات را می‌بندد | محدودیت باتری Android یا بسته‌شدن فرایند پس‌زمینه. | Battery optimization را غیرفعال کنید، wakelock را در صورت وجود فعال کنید و Termux را از لیست برنامه‌های اخیر حذف نکنید. |
